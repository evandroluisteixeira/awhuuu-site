# Awhuuu! — site

Site da marca Awhuuu! (rock, noite e estrada), publicado em https://awhuuu.com.br pelo GitHub Pages.

## Estrutura

- `index.html` — a página inteira: textos, estilos e o cálculo da Sexta de Lua Cheia.
- `img/` — emblema, palavra, ícones e imagem de compartilhamento.
- `CNAME` — o domínio do site (awhuuu.com.br). Não apagar.
- `favicon.ico` — ícone da aba do navegador.

## Como editar um texto

Abra `index.html` e procure a seção pelo comentário em maiúsculas (`<!-- MANIFESTO -->`, `<!-- EDITORIAS -->`, `<!-- CONTATO -->`). Os textos estão em português, entre as tags. Ao salvar na branch `main`, o site se atualiza sozinho em um ou dois minutos.
