# Artes dos carrosséis

`arte.py` desenha os cards no padrão do Awhuuu! (1080x1350 para o Instagram e a mesma arte no meio de 1080x1920 para o TikTok). `campanha.py` (Natal 2026) e `carta.py` são exemplos de uso.

Antes de rodar, baixe as fontes (licença OFL) para `fontes/`:

```
mkdir -p fontes && cd fontes
for f in anton/Anton-Regular.ttf spacemono/SpaceMono-Regular.ttf spacemono/SpaceMono-Bold.ttf blackopsone/BlackOpsOne-Regular.ttf; do
  curl -sfLO "https://raw.githubusercontent.com/google/fonts/main/ofl/$f"; done
```
